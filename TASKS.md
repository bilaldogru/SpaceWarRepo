# Space Defense Görev Listesi

Bu dosya, Space Defense projesini GitHub reposuna hazırlarken izlenecek görev sırasını göstermek için oluşturulmuştur.

## 1. Repo Hazırlığı

- [ ] GitHub üzerinde yeni repository oluştur.
- [ ] Repository adını proje adıyla uyumlu seç.
- [ ] Repository açıklamasına kısa bir proje tanımı ekle.
- [ ] Repo görünürlüğünü belirle: public veya private.
- [ ] Yerel proje klasöründe Git başlat.
- [ ] Uzak GitHub reposunu remote olarak ekle.
- [ ] İlk commit'i oluştur.
- [ ] Projeyi GitHub'a push et.

## 2. Dosya ve Klasör Düzeni

- [ ] `index.html`, `style.css` ve `js/` klasörünün çalıştığını kontrol et.
- [ ] `README.md` dosyasını son proje durumuna göre gözden geçir.
- [ ] `AI.md` dosyasındaki prompt ve açıklamaları kontrol et.
- [ ] `assets/` klasörüne ileride eklenecek görsel, ses veya referans dosyalarını yerleştir.
- [ ] `docs/` klasörüne ek açıklama, rapor veya proje notlarını ekle.
- [ ] `tests/manual/` klasörüne manuel test senaryolarını ekle.

## 3. GitHub İçeriği

- [ ] Repository ana sayfasında README'nin düzgün göründüğünü kontrol et.
- [ ] Gerekirse proje için konu etiketleri ekle.
- [ ] Oyun ekran görüntülerini `assets/screenshots/` klasörüne ekle.
- [ ] README içine ekran görüntüsü bağlantıları ekle.
- [ ] Harici asset kullanılırsa kaynak linklerini README'ye ekle.

## 4. Oyun Kontrol Listesi

- [ ] Ana menü açılıyor mu?
- [ ] Gezegen seçme ekranı çalışıyor mu?
- [ ] Her gezegen seçildiğinde oyun haritası açılıyor mu?
- [ ] Hazırlık modunda kule yerleştirilebiliyor mu?
- [ ] Turu Başlat butonu wave başlatıyor mu?
- [ ] Düşmanlar yolları takip ediyor mu?
- [ ] Ana üs canı doğru azalıyor mu?
- [ ] Para kazanma ve harcama sistemi doğru çalışıyor mu?
- [ ] Kule yükseltme sistemi çalışıyor mu?
- [ ] Laser, Missile ve Slow Field kuleleri beklenen davranışı gösteriyor mu?
- [ ] Scout, Tank ve Shielded Enemy türleri wave içinde geliyor mu?
- [ ] Oyun sonu ve zafer ekranları çalışıyor mu?

## 5. Kod Kalitesi

- [ ] JavaScript dosyalarında sözdizimi hatası olmadığını kontrol et.
- [ ] Gereksiz console çıktısı varsa temizle.
- [ ] Kullanılmayan dosya veya kod parçalarını kaldır.
- [ ] Değişken ve fonksiyon adlarının anlaşılır olduğundan emin ol.
- [ ] Kodun vanilla JavaScript ve Canvas API yapısını koruduğunu kontrol et.

## 6. Dokümantasyon

- [ ] README'deki kurulum adımlarını test et.
- [ ] README'deki oyun mekanikleri bölümünü son hâle göre güncelle.
- [ ] AI.md dosyasındaki yapay zeka kullanım açıklamasını kontrol et.
- [ ] Kullanılan promptların eksiksiz yazıldığını doğrula.
- [ ] Özgünlük açıklamasını gözden geçir.

## 7. Son Teslim Öncesi

- [ ] Projeyi temiz bir tarayıcı sekmesinde baştan sona dene.
- [ ] GitHub reposundaki dosyaların eksiksiz göründüğünü kontrol et.
- [ ] Son commit mesajını anlaşılır yaz.
- [ ] Gerekirse repo açıklamasına canlı demo veya kullanım notu ekle.
- [ ] Teslim edilecek bağlantının doğru repository adresi olduğundan emin ol.
